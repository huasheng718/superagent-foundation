Budget support is intentionally explicit. `metered` stops on reported usage and can lag incurred provider spend. `strict` token/cost execution is refused by current adapters. Opaque script/command workflow nodes cannot carry token/cost caps in either mode. No-progress-only policies remain supported. See [bounded execution](../bounded-execution.md) for the exact support matrix.

Governed execution requires Runner 0.12.0+; provider-receipt assignments require Runner 0.13.0+, enforced before queue and claim. Its assignment binds the retained Run context to the existing task manifest; measured source/effective resource digests accompany completion. See [Runner context protocol](../governed-context-protocol.md).

Formal content and governed experience remain separate lifecycles. Revoking a version or memory prevents subsequent execution and controlled publication; it cannot erase content already given to a running external process. See [governed intelligence](../governed-intelligence.md).

The controlled path creates a draft PR and never merges or enables auto-merge. Repository hosting rules independently require human review. Protect each actual contribution target, not only this platform source repository. A broad operator `gh` session does not establish least privilege. See [deployment acceptance](../operations/controlled-delivery.md).

The durable PR-create marker is consumed before the external request. If the process dies after marking but before sending, discovery can remain empty; manual reconciliation is required. An empty lookup does not authorize another automatic creation. Existing in-flight external effects cannot be atomically undone by controller cancellation.
